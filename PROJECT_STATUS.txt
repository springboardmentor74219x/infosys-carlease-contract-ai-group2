========================================================================
API ENDPOINTS
========================================================================

1. Upload Contract File
   POST /upload
   Body: multipart/form-data (file)
   Response: { "message": "Upload successful", "filename": "..." }

2. Get Negotiation Advice
   POST /negotiate
   Body: { "question": "How can I negotiate lower APR?" }
   Response: { "reply": "..." }

3. API Documentation
   GET /docs (Swagger UI)
   GET /redoc (ReDoc)
   GET /openapi.json (Raw OpenAPI spec)

========================================================================
TROUBLESHOOTING
========================================================================

Issue: Port 8000 already in use
  Solution: Kill existing process or use different port
  taskkill /PID <PID> /F
  python -m uvicorn main:app --port 8001

Issue: CORS Error
  Solution: CORS is enabled. Check backend is running.
  Verify: http://localhost:8000/docs loads

Issue: Web UI not loading
  Solution: Start web UI server
  python serve_ui.py

Issue: API connection timeout
  Solution: Check if backend is running
  python -m uvicorn main:app --host 0.0.0.0 --port 8000
