🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Backend won't start on port 8000:
  → Check if port is available: netstat -ano | findstr :8000
  → Kill process: taskkill /PID <PID> /F
  → Try different port: python -m uvicorn main:app --port 8001

CORS error in browser:
  → Ensure backend is running: http://localhost:8000/docs
  → CORS is configured in FastAPI
  → Refresh browser page

Web UI not loading:
  → Start web server: python serve_ui.py
  → Check port 5000: netstat -ano | findstr :5000
  → Refresh browser: http://localhost:5000/web_ui.html

API request timeout:
  → Verify backend is running
  → Check internet connection
  → Review logs in backend terminal
