🚀 HOW TO RUN THE PROJECT
================================================================================

EASIEST WAY (Recommended):
   Double-click: START_PROJECT.bat
   This automatically starts everything and opens the web UI in Chrome!

MANUAL METHOD (For development):
   Terminal 1: cd car_loan_backend
               python -m uvicorn main:app --host 0.0.0.0 --port 8000
   
   Terminal 2: python serve_ui.py
   
   Browser:    http://localhost:5000/web_ui.html

FLUTTER (Optional):
   cd car_loan_mvp
   flutter pub get
   flutter run -d chrome
